# ArtisanalBrew

<img src="./docs/repo/home.gif" alt="ArtisanalBrew home animation with a pixel robot crew collecting coffee coins" width="1000" />

_A fictional coffee storefront with multichain liquid staking and x402 agent commerce._

</div>

Run locally with Docker:

```bash
git clone https://github.com/AlejoReyna/ArtisanalBrew.git
cd ArtisanalBrew
cp .env.example .env
# Fill in the database and admin values in .env before starting.
docker compose up --build
```

Open [localhost:8080](http://localhost:8080).
